**Student:** Abdullah Farooq

## Project Description

This project moves from JavaScript running only in the console to JavaScript
controlling a real webpage. It covers selecting HTML elements, changing
their content and styles, creating and removing elements dynamically, and
responding to user interactions with event listeners.

## Concepts Learned

- The DOM (Document Object Model)
- Selecting elements: `getElementById`, `querySelector`, `querySelectorAll`
- Changing content: `textContent`, `innerHTML`
- Changing styles/classes: `style`, `classList`
- Creating elements: `createElement`, `appendChild`
- Removing elements: `.remove()`
- Handling user interaction: `addEventListener`

## Features

1. **Change Page Content** — Clicking a button updates the heading,
   paragraph, and the button's own text.
2. **Theme Changer** — Light Mode / Dark Mode buttons toggle the page
   background and text color using `classList`, with a live theme label.
3. **Counter App** — `+`, `-`, and Reset buttons control a shared counter.
4. **Dynamic List** — Add items to a list from a text input; the input
   clears after each add.
5. **Remove Items** — Every list item has its own Delete button that
   removes just that item.
6. **Live Character Counter** — A textarea's character count updates in
   real time as the user types.
7. **Interactive Student Profile (Mini Project)** — Clicking "Update
   Profile" dynamically replaces the Name, Department, Semester, Skills,
   and Profile Image using a JavaScript data object. No updated
   information is hard-coded in the HTML.
