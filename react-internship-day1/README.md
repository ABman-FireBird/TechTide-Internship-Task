# React Internship Day 1 — Personal Profile Page

## Project Description
A responsive personal profile page built with React and Tailwind CSS as part of the TechTide Corporation React.js internship, Day 1 assignment. The page displays personal information, skills, and contact links using reusable components.

## Technologies Used
- React
- Vite
- JavaScript
- Tailwind CSS

## React Concepts Learned
- Creating a React app with Vite
- JSX syntax and rendering
- Functional components
- Component reusability (Navbar, Profile, Skills, Footer)
- Rendering dynamic data using JavaScript variables
- Rendering lists/arrays using `.map()`
- Styling with Tailwind CSS

## How to Run the Project
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
4. Open the local server URL shown in the terminal
